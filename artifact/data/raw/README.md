Place the official GroupLens `ml-1m.zip` archive in this directory.

Expected MD5: `c4d9eecfca2ab87c1945afe126590906`.

The dataset is intentionally not redistributed in this artifact.

For TUM RGB-D, run
`python experiments/017_tum_motor_composition/download_data.py` from the
artifact root. It obtains the 47 official ground-truth trajectory files and
places them in `tum_rgbd_groundtruth/`. The reported checksums manifest is
included there; trajectory files are intentionally not redistributed.
